Key Design Decisions

  • LangGraph StateGraph for workflow orchestration with explicit state transitions
  • SQLite Checkpoint Saver for durable state persistence across restarts
  • SSE Streaming via FastAPI's StreamingResponse for real-time updates
  • Event-driven architecture with explicit events for stage transitions
  • Separation of concerns: workflow logic in backend, UI in frontend, no coupling
