Migrating from Approach 2 to Approach 3

How hard is it to upgrade later?

Migration Effort: Moderate

What changes, what stays the same
Component Approach 2 Approach 3 Change?

Estimated Migration Effort

~1-2 days of development

  • Replace custom event queue with LangGraph's astream()
  • Add checkpoint saver (SqliteSaver or PostgresSaver)
  • Update SSE endpoint to yield LangGraph chunks
  • Update frontend to handle LangGraph's event format
  • Test resumption from checkpoints

Key Consideration

Approach 3 provides resume capability (restart from last checkpoint after crash). Approach 2 must restart the entire workflow. If you plan to run long workflows (30+ min), Approach 3 is worth starting with directly.

Given your PoC is quick workflows, Approach 2 is fine for now. Migration to 3 later is straightforward.
