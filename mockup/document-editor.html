Architecture Overview
Microservices architecture deployed on AWS using Kubernetes (EKS). The system consists of:
1. API Gateway
Route 53 → ALB → API Gateway service
2. Frontend Service
React SPA served via CloudFront
3. Backend Services
User service, Product service, Order service, Payment service
4. Data Layer
RDS PostgreSQL (primary), ElastiCache Redis (cache), S3 (storage)
